# Ankitha Venkatesh · Design Journal

## Setup
1. Place your photograph (`IMG-20261125-WA0001_2.jpg`) in this folder alongside `index.html`.
2. Open the folder in VS Code and launch `index.html` with Live Server (or open directly in your browser).

## Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: Ankitha Venkatesh Design Journal"
git branch -M main
git remote add origin https://github.com/ankithavenkatesh04/design-journal.git
git push -u origin main
```
